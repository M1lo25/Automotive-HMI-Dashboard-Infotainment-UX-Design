# Automotive-HMI-Dashboard-Infotainment-UX-Design

This project explores the design of a Human-Machine Interface (HMI) for high-end Bentley vehicles, with a strong focus on **user experience (UX)** and the **optimization of driver-vehicle interaction**.

The prototype includes:

- **Driver-focused infotainment system**, featuring:

  - Interactive map navigation with active routing;  
  - Multimedia controls (radio, Bluetooth, audio tracks);  
  - Voice commands and contact management;  
  - Comprehensive vehicle settings.

Each section is designed to **reduce cognitive load while driving**, in accordance with **international automotive HMI guidelines**, using a modular, scalable, and accessible design approach.

### Additional Features Developed

- Selection of **driving modes** with advanced controls (*Start & Stop*, *Traction Control*, *Launch Control*, etc.).  
- **Ambient lighting** management with color selection, intensity, and time scheduling.  
- Selectable **in-cabin fragrance** system.  
- System settings (language, date/time, firmware, Bluetooth, Wi-Fi).  
- Interface for **pairing and managing mobile devices**.  
- Multi-screen layout inspired by **next-generation digital dashboards**.
